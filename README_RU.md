# VIBECOMIX — запуск на Windows

VIBECOMIX — браузерный редактор страниц комикса. Это исходный проект на React, TypeScript и Vite, а не отдельный `index.html`.

## Что установить один раз

1. Установите Node.js LTS с официального сайта Node.js.
2. Скачайте и распакуйте проект.

## Первый запуск

Откройте PowerShell или Windows Terminal **в папке проекта, рядом с `package.json`**, и выполните:

```powershell
npm ci
npm run dev
```

Когда Vite напечатает адрес, откройте его в браузере. Для этого проекта обычно это `http://localhost:3000`.

Не закрывайте окно терминала, пока работает редактор. Чтобы остановить сервер, нажмите `Ctrl+C`.

## Последующие запуски

После установки зависимостей достаточно выполнить:

```powershell
npm run dev
```

Либо дважды щёлкнуть `start.bat` в папке проекта. Скрипт проверит наличие Node.js, при необходимости установит npm-зависимости и сам откроет браузер. Node.js всё равно должен быть установлен: этот BAT-файл предназначен для локального запуска разработчиком.

## Проверка production-сборки

```powershell
npm run build
npm run preview
```

Vite напечатает адрес предпросмотра, обычно `http://localhost:4173`.

## Почему нельзя открыть `index.html` двойным щелчком

`index.html` подключает `src/main.tsx`. Браузер не преобразует TypeScript/JSX и не устанавливает библиотеки React. Это делает Vite. Поэтому простой статический сервер в корне исходников, в том числе `npx serve`, тоже не заменяет сборку.

Если нужен именно статический сервер, сначала соберите проект (`npm run build`), а потом раздавайте каталог `dist`.

## Альфа-тестирование

`start.bat` — это локальный запуск исходного проекта и он требует Node.js. Для альфа-тестеров удобнее дать веб-ссылку: зависимости уже будут включены в собранное приложение, и участникам понадобится только современный браузер. Не отправляйте тестерам ZIP с исходниками, если им не нужно заниматься разработкой.

## Проекты

Рабочая копия автоматически сохраняется в браузере на этом компьютере. Чтобы перенести работу в другой браузер или на другой компьютер, используйте в редакторе кнопки открытия и сохранения файла проекта `.vibeco`.

## Экспорт

В панели экспорта выберите формат и область: все листы, текущий лист или выбранный фрейм. PNG/JPG одного листа скачивается отдельным изображением; экспорт всех листов и ZIP-последовательность создают один архив с нумерованными файлами и `manifest.json`. Выбранный фрейм обрезается по его границам; PNG сохраняет прозрачность за пределами непрозрачной формы.

HTML-плеер содержит выбранные листы и встраивает изображения в файл, поэтому исходные изображения не нужны при открытии. Если браузер не может прочитать внешний ресурс из-за доступа или CORS, экспорт покажет ошибку, а не создаст неполный файл.

GIF кодируется как настоящий GIF, ограничен 1080p и 600 кадрами. WEBM записывается средствами браузера; MP4 доступен только если браузер действительно поддерживает создание MP4. Формат файла не подменяется переименованием расширения. При экспорте нескольких листов в GIF/видео каждый лист показывается выбранное число секунд; слишком большой экспорт блокируется с подсказкой по уменьшению длительности или FPS.
