# VIBECOMIX — запуск на Windows

VIBECOMIX — браузерный редактор страниц комикса. Это исходный проект на React, TypeScript и Vite, а не отдельный `index.html`.

## Что установить один раз

1. Установите Node.js LTS с официального сайта Node.js.
2. Скачайте и распакуйте проект.

## Первый запуск

Откройте PowerShell или Windows Terminal **в папке проекта, рядом с `package.json`**, и выполните:

```powershell
npm ci
npm run dev
```

Когда Vite напечатает адрес, откройте его в браузере. Для этого проекта обычно это `http://localhost:3000`.

Не закрывайте окно терминала, пока работает редактор. Чтобы остановить сервер, нажмите `Ctrl+C`.

## Последующие запуски

После установки зависимостей достаточно выполнить:

```powershell
npm run dev
```

Либо дважды щёлкнуть `start.bat` в папке проекта. Скрипт проверит наличие Node.js и при необходимости установит зависимости.

## Проверка production-сборки

```powershell
npm run build
npm run preview
```

Vite напечатает адрес предпросмотра, обычно `http://localhost:4173`.

## Почему нельзя открыть `index.html` двойным щелчком

`index.html` подключает `src/main.tsx`. Браузер не преобразует TypeScript/JSX и не устанавливает библиотеки React. Это делает Vite. Поэтому простой статический сервер в корне исходников, в том числе `npx serve`, тоже не заменяет сборку.

Если нужен именно статический сервер, сначала соберите проект (`npm run build`), а потом раздавайте каталог `dist`.

## Проекты

Рабочая копия автоматически сохраняется в браузере на этом компьютере. Чтобы перенести работу в другой браузер или на другой компьютер, используйте в редакторе кнопки открытия и сохранения файла проекта `.vibeco`.
